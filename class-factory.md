# COURSE CONTENT

## Prerequisites

CSCI 1012 or equivalent introductory programming course.

## Course Description

This course introduces students to agentic engineering — the design, development, and deployment of systems that leverage large language model (LLM) agents to solve complex problems and build real products. Students will learn essential workflows, version control with Git and GitHub, project management practices, and techniques for orchestrating agentic systems. Through hands-on exercises and a capstone team project, students will deploy agents on the web, implement continuous improvement pipelines using GitHub Actions, and evaluate LLM outputs for quality and correctness. No prior experience with R or Python is required; both languages will be used as tools by the agents themselves.

## Learning Objectives

By the end of this course, students will be able to:

1. **Design and deploy** an agentic workflow from problem statement to production
2. **Debug agent behavior** and diagnose failures in reasoning and tool use
3. **Build multi-agent systems** that coordinate to solve complex tasks
4. **Evaluate LLM outputs** for correctness, bias, and fitness for purpose
5. **Deploy products on the web** using GitHub as version control and distribution platform
6. **Deploy continuous improvement workflows** using GitHub Actions and automated testing

## Topics Covered

- Introduction to agentic systems and LLM capabilities
- Claude Code core tools and workflows
- Context management and document injection
- Conversation flow control and planning modes
- Custom commands and workflow automation
- Skills: building and leveraging custom skills
- GitHub integration and automated workflows
- Hooks and advanced extensions
- Web deployment and integration
- Evaluation and quality assurance for agent outputs
- Project management and team collaboration

## Assessment Types

### Individual Assignments (40%)
Each week (Weeks 2–9), students complete a small, project-based assignment in which they use Claude Code to build or analyze something concrete. Each assignment is delivered as a **GitHub repository** and includes the **full conversation history** with Claude Code showing prompts, Claude's responses, iterations, and refinements. Grading focuses on:
- Clarity and quality of initial prompts
- Evidence of iterative collaboration (asking Claude to refine, debug, or extend)
- Final product quality and functionality
- Thoughtful use of Claude Code features (planning modes, custom commands, document injection, etc.)

Each assignment is graded out of 10 points.

### Team Project (40%)
Students form teams of 3–4 in Week 4–5 and propose a real-world problem to solve using agentic systems. The team project spans Weeks 10–15 and is assessed via three submissions:

**Proposal (Week 4–5)**: 2–3 page written proposal including problem statement, proposed solution approach, team roles, and GitHub repository setup. (5 points)

**Interim Report (Week 11)**: 2–3 page status update with progress to date, challenges faced, next steps, and evidence of continued GitHub collaboration (commits, PRs, conversation logs). (10 points)

**Final Report (Week 15)**: 5–7 page final project report including problem statement, solution architecture, implementation details, results/evaluation, lessons learned, and GitHub repository with full codebase and conversation history. (15 points)

### Final Presentation (10%)
In Week 16, each team presents their project to the class in a 15-minute talk plus 5 minutes Q&A. Grading is based on clarity of presentation, quality of visuals, and ability to articulate the problem, solution, and lessons learned. (10 points)

### Participation (10%)
Participation is assessed through:
- Active engagement in in-class exercises and live coding (students share their screens, ask questions, collaborate on solutions)
- Attendance and on-time arrival (more than 3 unexcused absences or chronic lateness will reduce this grade)
- Peer feedback and collaboration during team project
- Constructive participation in class discussions

(10 points total across the semester)

## Generative-AI Use Policy

Generative-AI tools (such as ChatGPT, Claude, or Copilot) may be used only as explicitly permitted for a given assignment. **For this course:**

- **Claude Code in individual assignments (Weeks 2–9)**: You are **required** to use Claude Code and must disclose the full conversation history (prompts and Claude's responses) as part of your submission. This is not "cheating" — it is the core skill of the course.
- **Other generative-AI tools (ChatGPT, Copilot, etc.)**: May be used only for research, brainstorming, or learning (e.g., "explain this error message"), not for generating code or solutions you submit. Any use must be disclosed.
- **Team project**: The team must disclose all use of generative-AI tools and how they were used. Undisclosed AI use is a violation of academic integrity.

When generative-AI is permitted, you must disclose which tool you used and how, and you remain fully responsible for the correctness and originality of everything you submit. Using these tools where they are prohibited, or submitting their output as your own unaided work, is a violation of academic integrity.
